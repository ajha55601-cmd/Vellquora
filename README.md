# Vellquora - Premium Ecommerce Web Project

Vellquora is a responsive full-stack ecommerce website developed as a Capstone Web Project for Web Technologies (23CSE404).

The project demonstrates the integration of:

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL

It includes frontend UI, backend authentication, database integration, sessions, cookies, and CRUD operations.

# Installation Guide

## Step 1
Install XAMPP.

## Step 2
Move project folder into:

```txt
C:\xampp\htdocs\
```

## Step 3
Start:
- Apache
- MySQL

from XAMPP Control Panel.

## Step 4
Open phpMyAdmin:

```txt
http://localhost/phpmyadmin
```

Create database:

```txt
vellquora
```

Import:

```txt
database.sql
```

## Step 5
Run project:

```txt
http://localhost/vellquora
```
